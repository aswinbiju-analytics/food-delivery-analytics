# 🍔 Food Delivery Analytics

## 📊 Project Overview

Food Delivery Analytics is an end-to-end Data Analytics project that analyzes food delivery orders, revenue, customer behavior, delivery performance, and operational factors.

The project uses Python, MySQL, and Power BI to transform raw food delivery data into meaningful business insights through data cleaning, exploratory data analysis, SQL analysis, and interactive dashboard development.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall food delivery order performance
- Calculate total revenue and average order value
- Identify popular food items
- Analyze location-wise order and revenue performance
- Compare different delivery methods
- Analyze delivery delays
- Study customer satisfaction
- Analyze loyalty program behavior
- Understand monthly order trends
- Examine traffic and weather conditions
- Build an interactive Power BI dashboard
